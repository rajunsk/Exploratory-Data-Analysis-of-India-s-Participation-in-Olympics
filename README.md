#  Indian Olympic Analysis – Power BI Dashboard

##  Overview
This Power BI project analyzes India's performance in the Olympic Games.  
It explores medals by sport, gender, city, and year, and highlights top athletes.

##  Key Insights
- Total medals won by India across years
- Gender-wise participation and medal trends
- Top sports and athletes contributing to success

## Files Included
- `Indian_Olympic_Analysis.pbix` → Power BI dashboard
- `olympics_data.csv` → Dataset used
- `EDA.ipynb` → Exploratory Data Analysis (Python)

##  Tools Used
- Power BI
